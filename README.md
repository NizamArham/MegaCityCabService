# MegaCityCabService

AdvancedProgrammingProject

## Project Overview

Mega City Cab Service is a web-based system designed to streamline the operations of the Mega City Cab Service, a popular cab company in Colombo City. The system allows the company to manage customer bookings, calculate bills, and manage drivers and vehicles efficiently.

## Features

- **Customer Booking Management**: Allows customers to book cabs, view booking details, and calculate fares.
- **Driver Management**: Manage driver details and assign them to customer bookings.
- **Admin Dashboard**: Admins can view and manage customer bookings, driver assignments, and other system details.
- **Authentication**: Secure login system for users with different roles (Admin, Driver, Passenger).
- **Automation Testing**: Includes automation tests for core functionalities.

## Repository Structure

The repository is divided into the following sections:

- **`/backend`**: Java-based backend for managing database connections, user roles, and server-side logic.
- **`/frontend`**: React-based frontend for interacting with the user and displaying relevant information.
- **`/documentation`**: Contains all the documentation, including system design, UML diagrams, and testing reports.

## Installation

### Prerequisites

1. Ensure that you have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed for the frontend.
2. Ensure that you have [Java](https://www.oracle.com/java/technologies/javase-downloads.html) and [Tomcat](http://tomcat.apache.org/) for the backend.
3. Set up a database (e.g., MySQL) using XAMPP or any preferred local server.

1. Clone the repository:
